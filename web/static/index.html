一、快速开始(check 模式,类似 httpx)

最简单的用法:只填目标 URL,不填字典。spray 会对每个目标发一个请求,收集状态码、标题、指纹、敏感信息。

  • 「URL」框填 http://example.com,每行一个
  • 不勾选任何字典/掩码,直接点「开始扫描」
  • 右侧表格实时显示:状态码、响应长度、耗时、URL、标题、指纹、来源

二、目录爆破(brute 模式,类似 dirsearch)

提供字典后自动进入 brute 模式,对目标 + 字典里每个词发请求探测有效路径。

  • 「字典文件」点「选择并上传字典」,选中本地 txt 字典文件(每行一个词),可多选
  • 上传后自动用绝对路径传给 spray,不用手填路径
  • 常用字典:dirsearch 的 dicc.txt、raft 目录、常见后台路径
  • 「扩展名」可填 php,asp,jsp 给每个词加后缀;勾「强制扩展名」强制给每个词加后缀
  • 「掩码」可填 {?l#4} 生成4位小写字母组合;也支持 {?d#3} 数字、{?ld#2} 混合
  • 「规则文件」:对字典每个词用 hashcat 规则变形。例:在「规则文件」填 rule.txt,内容 : 保留原词、l 小写、c 首字母大写、$1 追加 1。多个规则文件逗号分隔。配合「过滤规则」如 >8 只保留长度>8 的结果
  • 勾选「默认字典」加载 spray 自带默认字典;勾「大写」「小写」对所有词做大小写变换

三、指纹识别 / 插件

勾选即启用,多选叠加,也可勾「全部」一键开启所有插件。

  • 全部:一键启用全部插件(指纹/备份/常见/爬虫/主动/侦察/凭证/漏洞验证)
  • 指纹:主动探测常见指纹目录,集成 gogo/fingerprinthub/wappalyzer/ehole/goby/nmap/favicon 等指纹库
  • 备份:对发现的每个有效路径追加 .bak/.zip/.sql/.swp 等备份后缀爆破,找遗留文件
  • 常见:探测常见通用文件(.git/.env/log 等)
  • 爬虫:爬虫,自动从响应里提取新 URL 继续扫,「爬虫深度」默认 3
  • 主动:主动探测常见后台管理路径(/admin/manage/login 等)
  • 侦察:在响应里提取邮箱、IP、敏感信息(配合 info/pentest 标签)
  • 凭证:检测常见密钥/凭证泄露(AWS/GitHub/Stripe 等 token)
  • 漏洞验证:指纹识别后用 neutron 模板做 PoC 验证(需配合「指纹」使用)
  • 备份生成:用 fuzzuli 思路自动生成备份文件字典

四、过滤 / 输出

控制哪些响应算"有效"以及输出内容。

  • 状态码:默认 200 白名单、400/410 黑名单。改成「白状态」「黑状态」可自定义,如 200,301、500,502
  • 匹配表达式:用 expr-lang 表达式只保留符合条件的响应。例:current.Status != 200、current.BodyLength > 1000、"admin" in current.Title
  • 过滤表达式:过滤掉不符合条件的响应。例:current.Body contains "Powered by"、current.Status in [403, 404]
  • 模糊输出:基于 simhash 相似度去重,识别"全站都返回同一个 404 页面"这种情况,保留差异化的响应
  • 去重:对 403/200/404 等状态码的响应做去重,每个状态只显示第一个
  • 完整字段参考(current 可用字段):Status、BodyLength、Body、Title、UrlString、ContentType、HeaderLength、RedirectURL、Frameworks、IsValid、IsFuzzy

五、批量与多目标

  • URL 框每行一个目标,或用「URL 文件」指向一个 txt
  • 支持 CIDR:填 10.0.0.0/24,配合「端口」80,443,8080
  • 「并发 pool」控制同时扫多少个目标,「线程 thread」控制每目标并发请求数

六、停止扫描

点「停止」立即终止当前扫描,spray 内部通过 context 取消,已扫到的结果保留在表格里。再次点「开始」是新扫描。
